# Gloam audio license register

No third-party audio asset is currently installed. The bundled Tiny Swords pack
contains no audio. This is deliberate: Gloam will not ship synthesized
placeholders or an unverified download.

Before adding any file, record its event id, local path, source URL, author,
license version, attribution wording, redistribution confirmation, and SHA-256
checksum here. The corresponding path must then be added to
`scripts/audio_asset_manifest.gd`.
